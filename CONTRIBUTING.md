# Contributing

1. Read `AGENTS.md`.
2. Create a task branch; do not commit to `main`.
3. Link every change to a task or requirement ID.
4. Keep patches small and explain their upstream origin.
5. Add or update tests and docs with every behavior change.
6. Record exact commands and raw logs.
7. Do not commit credentials, keys, tokens or device backups.
8. Do not merge or release without review.
9. Never perform router-side changes outside the approval protocol.
