# Agent Roles

The orchestrating Gemini agent must read `AGENTS.md` and delegate only scoped work. Specialist roles do not override the project-wide contract.

Suggested roles:
- Researcher: source/repository/license audit.
- Implementer: code and patch implementation.
- Test Engineer: test design, execution and evidence.
- Reviewer: independent code/design/risk review.

For the initial P1 discovery, use researcher + reviewer roles only. Do not start implementation.
