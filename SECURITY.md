# Security Policy

- Never commit WireGuard private keys, passwords, API tokens, SSH keys or backups containing secrets.
- Redact public IPs, MAC addresses, serial numbers and account identifiers unless essential.
- Do not expose SSH, LuCI or management interfaces to WAN.
- Track kernel and package security advisories.
- Record provenance and SHA-256 for binaries.
- Report vulnerabilities privately to the project owner; do not publish exploit details in routine reports.
